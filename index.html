SSPBI — prototype

Ask-a-Measure

Type a plain-English question about AIM data and get back the matching SSPBI measure and its DAX — instead of hunting through the data-pane folder tree.

Prototype only — matching runs on a small local keyword rule set (see PROTOTYPE_NOTES.md), not a live language model or the production measure store. It's meant to demonstrate the interaction, not ship as-is.
